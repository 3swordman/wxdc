# WXDC

A single-user canteen ordering application built with Vite and Cloudflare Workers. It supports DeepSeek meal selection, manual order review, and optional scheduled ordering.

See [WORKERS.md](WORKERS.md) for local setup, configuration, tests, and deployment. Scheduled generation and automatic submission are disabled by default.

Legacy documentation, configuration, and local data are preserved in the git-ignored `backup/` directory. The Worker does not import or upload this data automatically.
