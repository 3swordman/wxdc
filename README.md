# WXDC

A single-user canteen ordering application for [Shenzhen Experimental School Senior High School Department](https://zh.wikipedia.org/zh-hk/%E6%B7%B1%E5%9C%B3%E5%AE%9E%E9%AA%8C%E5%AD%A6%E6%A0%A1#%E6%B7%B1%E5%9C%B3%E5%AE%9E%E9%AA%8C%E5%AD%A6%E6%A0%A1%E9%AB%98%E4%B8%AD%E9%83%A8) built with Vite and Cloudflare Workers. It supports DeepSeek meal selection, manual order review, and optional scheduled ordering.

See [WORKERS.md](WORKERS.md) for local setup, configuration, tests, and deployment. Scheduled generation and automatic submission are disabled by default.
